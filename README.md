# Feed pembaruan ALTIS / ALTIS update feed

Situs statis berisi feed pembaruan bertanda tangan untuk [ALTIS Edisi Komunitas](https://github.com/arjunaayasa/altis).
Instalasi ALTIS membaca `stable/feed.json`, `feed.sig`, dan `freshness.json` dari
`https://arjunaayasa.github.io/altis-feed`, lalu memeriksa tanda tangannya terhadap kunci root yang tertanam di
`app.js`. Isi folder ini dibuat oleh `feed:build` dan `altis-sign freshness sign`; jangan disunting dengan tangan.

The static site of the signed update feed for [ALTIS Community Edition](https://github.com/arjunaayasa/altis).
Installations read `stable/feed.json`, `feed.sig` and `freshness.json` from `https://arjunaayasa.github.io/altis-feed`
and check the signatures against the root keys embedded in `app.js`. Generated by `feed:build` and
`altis-sign freshness sign`; do not edit by hand.
